Archlinux更新报错：signature is marginal trust

2022-08-05
:: tags:  #Linux

signature is marginal trust

41天没更新，更新时出现： signature from "David Runge dvzrv@archlinux.org" is marginal trust

需要先更新key：

pacman -S archlinux-keyring

修复Archlinux上的GPGME error

1. 删除旧的同步的db文件

sudo rm /var/lib/pacman/sync/*

2. 重新生成pacman-key

sudo pacman-key --init

3. 重新Populate pacman-key

sudo pacman-key --populate

4. 重新同步

sudo pacman -Syyu

之后就可以正常更新了
