对广播地址进行ping

2025-04-05
:: tags:  #计算机网络

直接ping 同网段的广播地址，相当于直接向整个网段的主机发送ping。然后你会看到不同主机的ICMP echo reply。 有一个前提就是其它主机没有限制对广播地址的ping请求。linux和windows默认都没有限制。

如果要禁止响应对广播地址的ping请求 linux系统执行： sysctl -w net.ipv4.icmp_echo_ignore_broadcasts=1

windows要禁用网络发现功能 ，执行 netsh advfirewall firewall set rule group="Network Discovery" new enable=No

需要 ping -b，否则会提示Do you want to ping broadcast? Then -b. If not, check your local firewall rules.
