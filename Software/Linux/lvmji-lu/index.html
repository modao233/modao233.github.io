LVM记录

2021-06-01
:: tags:  #Linux  #Software

重装了下系统，用上了LVM

LVM：

  • 物理卷PV
  • 卷组VG：将物理卷划分为可分配的逻辑块
  • 逻辑卷LV：多个逻辑块组成固定大小

流程：多个磁盘/分区/raid-->多个物理卷PV-->合成卷组VG-->从VG划分出逻辑卷LV-->格式化LV，挂载使用。
